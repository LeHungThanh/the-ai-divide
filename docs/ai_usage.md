# AI assistance disclosure

OpenAI Codex assisted with the Streamlit application structure, Python implementation, chart design, data-selection logic, reproducibility scripts, documentation, and automated tests. Numerical evidence is drawn from the bundled Eurostat source snapshots. The project does not infer absent observations, fabricate an EU aggregate, or substitute generated values for the source data. Regenerating the processed CSVs reproduces the checked-in values. The group remains responsible for the code, evidence, interpretation, and final submission.

The repository bundles raw JSON-stat API responses and a manifest so source observations, hashes, and indices can be independently checked. The published 2025 expertise-barrier discrepancy is disclosed in the app and methods documentation. The [team AI provenance matrix](ai_provenance_matrix.md) records reconstructed prompt summaries, associated repository artefacts, expected AI-assisted outputs, and falsifiable verification procedures for the four workstreams. These are not verbatim prompt transcripts or evidence that an individual verification was personally performed. Model versions were not recorded.
