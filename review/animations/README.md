# Animation and Adoption Barriers browser evidence

Captured in the `codex/ai-divide-animations` worktree at 1366×768. `*-viewport.png` are settled-page views from the six-page animation audit, and `entrance.gif` shows a verified Overview page transition. `barriers-before-viewport.png` is the stable `c52252a` Adoption Barriers page. `barriers-after-viewport.png` and the numbered `barriers-after-section-*.png` are the redesigned page at the same viewport, captured while scrolling through its full height.

The shared motion system uses CSS opacity and an 8px upward settle over 320–340ms, staggered KPI cards, and 160–180ms hover/focus transitions. Adoption Barriers uses the CSS page-entry treatment and native chart hover, but disables Plotly data interpolation on redraw; the browser preference cannot be passed to Plotly without adding JavaScript. This keeps filter updates stable and lets the reduced-motion stylesheet disable all nonessential page motion. The other five pages retain the shared Plotly 240ms transition. Browser checks confirmed page-entry motion on navigation, no entrance replay after filter reruns, responsive layout without horizontal overflow, and working filter updates. The available browser automation could not emulate `prefers-reduced-motion` directly.

The Adoption Barriers page adds a 10–49 vs 250+ dumbbell chart and a Member State vs official EU27 grouped bar comparison. Both show exact values and signed percentage-point gaps in tables; plotted marks omit missing observations. Screenshots show defaults, both visualizations, source details and quality flags.
